# MPWA Node Backend (Railway)

WhatsApp multi-device Node backend (Baileys) for MPWA panel.

## Railway deploy
1. Connect this repo to Railway
2. Set environment variables (see `.env.example`)
3. Add volume at `credentials`
4. Custom domain: `wa.royalthakurofficial.xyz`
5. Panel: Server Type Other, Port 443, URL https://wa.royalthakurofficial.xyz

## Start
```
npm install
npm start
```
